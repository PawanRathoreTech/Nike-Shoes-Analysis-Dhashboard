## 📊 Project Overview
This project presents a detailed **sales analysis of Nike shoes** using an
interactive **Power BI dashboard**.  
The analysis focuses on **regional performance, monthly sales trends, product-level insights,
pricing, ratings, and profitability** to support data-driven business decisions.

## 🔧 Tools & Technologies Used
- **Power BI** – Dashboard design & data visualization  
- **SQL** – Data extraction, filtering, and transformation  
- **DAX** – Calculated measures & KPIs  
- **Excel / CSV** – Data source

- ## 📌 Dashboard Pages
The dashboard is divided into three main sections:

### 🔹 Overview
- Year-wise unit sales comparison (2020 & 2021)
- Monthly unit sales trend
- Region-wise unit sales distribution
- Overall profit analysis

### 🔹 Insight
- Product-level analysis (Air Jordan series)
- Sale price vs listing price comparison
- Customer reviews and ratings
- Individual product performance insights

### 🔹 Performance
- Regional sales performance comparison

- 
- Monthly sales fluctuations
- Profit contribution by region
- High-performing vs low-performing regions

- ## 📊 Key Metrics Highlighted
- Total Units Sold (Year-wise)
- Monthly Units Sale Trend
- Profit Analysis
- Sale Price & Listing Price
- Product Ratings & Reviews
- Region-wise Performance
